# Chemical Nomenclature Tools

Interactive naming practice for general and organic chemistry students.

**Use it:** https://lufox2021.github.io/Chemical-Nomenclature-Tools/

- Inorganic: https://lufox2021.github.io/Chemical-Nomenclature-Tools/inorganic/
- Organic: https://lufox2021.github.io/Chemical-Nomenclature-Tools/organic/

## Nomenclature Review Tool (inorganic)

- **Review** – the naming rules with worked examples, and full ion tables.
- **Practice** – unlimited problems in nine topics (fixed- and variable-charge metals, polyatomic ions, hydrogen-anion salts, binary molecular compounds, binary acids, oxyacids, hydrates), formula → name and name → formula, with hints and targeted feedback.
- **Quiz** – 10 points per question; drawing a correct Lewis structure (molecules, acids, polyatomic ions) earns 15. Scores are saved in the student's browser and charted on **My Progress**.
- **Instructor** – choose topics and quiz length, add problems by form or spreadsheet, export Blackboard question files, and share settings with a student link.
- Every answer is shown as a rotatable 3D model.

## How answers are checked

An answer passes if it identifies exactly one compound. Names are not case- or spacing-sensitive; correct but nonstandard answers (older names, unneeded Roman numerals, prefixes on ionic compounds) pass with a note giving the standard form. Drawn structures must show every hydrogen, lone pair and formal charge, and use the formal-charge-minimizing structure for expanded octets.

## Organic Nomenclature Review

- **Two directions:** Name → Structure (students draw a skeletal structure with wedges and dashes) and Structure → Name (students type the IUPAC name).
- **301 built-in compounds** in 11 topics: alkanes, cycloalkanes, haloalkanes, alkenes and alkynes, alcohols/ethers/thiols, amines, aldehydes and ketones, acids and derivatives, benzene derivatives, R/S stereochemistry, multifunctional compounds.
- **Grading (10 / 5 / 0):** drawings are compared with the answer as molecular graphs, so orientation and drawing order don't matter. Typed names are read back into structures: prefix order, capitals and old-style locants don't matter. Five points for the right compound with wrong or missing R/S or E/Z, a broken naming rule (numbering, parent chain), or an ion missing its lone pairs.
- **Stereochemistry help:** the ⟲ Orient tool turns a drawing so the lowest-priority group points back (with CIP priorities and the 1 → 2 → 3 arrow in Practice), and wrong stereocenters open a rotatable 3D model with a "Turn so 4 points back" button.
- **Instructor:** topics, quiz length, directions, common names on/off, problem bank (form, spreadsheet, PubChem lookup), Blackboard export (multiple choice, and fill-in-the-blank with structure figures).

Each tool is a single self-contained `index.html` file in its own folder (`inorganic/`, `organic/`). The `index.html` at the top is a landing page that links to them.
