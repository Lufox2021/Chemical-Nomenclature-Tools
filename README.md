# Chemical Nomenclature Tools

Interactive naming practice for general chemistry students.

**Use it:** https://lufox2021.github.io/Chemical-Nomenclature-Tools/

- Inorganic: https://lufox2021.github.io/Chemical-Nomenclature-Tools/inorganic/
- Organic (coming soon): https://lufox2021.github.io/Chemical-Nomenclature-Tools/organic/

## Nomenclature Review Tool (inorganic)

- **Review** – the naming rules with worked examples, and full ion tables.
- **Practice** – unlimited problems in nine topics (fixed- and variable-charge metals, polyatomic ions, hydrogen-anion salts, binary molecular compounds, binary acids, oxyacids, hydrates), formula → name and name → formula, with hints and targeted feedback.
- **Quiz** – 10 points per question; drawing a correct Lewis structure (molecules, acids, polyatomic ions) earns 15. Scores are saved in the student's browser and charted on **My Progress**.
- **Instructor** – choose topics and quiz length, add problems by form or spreadsheet, export Blackboard question files, and share settings with a student link.
- Every answer is shown as a rotatable 3D model.

## How answers are checked

An answer passes if it identifies exactly one compound. Names are not case- or spacing-sensitive; correct but nonstandard answers (older names, unneeded Roman numerals, prefixes on ionic compounds) pass with a note giving the standard form. Drawn structures must show every hydrogen, lone pair and formal charge, and use the formal-charge-minimizing structure for expanded octets.
